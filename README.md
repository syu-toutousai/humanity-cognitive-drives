# 人間性を動かす三つの装置

> パターン性向・意図バイアス・因果の錯覚
> Patternicity · Intentionality Bias · Causal Illusion
> 模式偏执 · 意图偏见 · 因果执念

人間は世界をありのままに見ない。ノイズから形を抜き出し、形に主体を読み、出来事を因果で縫い合わせる。宗教も科学も陰謀論も、この同じ一本の線から生まれる。

## 三つの装置

### 01 パターン性向

**Patternicity / Apophenia / 模式偏执**

> 無意味なノイズの中に、意味のあるパターンや相関を読み込んでしまう傾向。
> *The tendency to detect meaningful patterns in meaningless, random data.*
> 在无意义的随机数据中强行寻找有意义模式的倾向。

雲が動物に見える。星を結んで星座にする。偶然続いた災厄に「巡り合わせ」を読む。脳は、信号とノイズの境界が曖昧な世界で、まず「形がある」と仮定する。

この過剰適合は欠陥ではなく、設計の副作用だ。猛獣の気配を見落とすコストは、風の音を猛獣と誤認するコストより、はるかに高い。偽陽性を恐れない知覚は、生存に適していた。言語、芸術、科学の仮説も、この装置から出てくる。ただし同じ装置が、陰謀論や宏大な歴史哲学も生産する。

**関連語:** アポフェニア / 空想性錯視 / 過剰適合 / 偽陽性コスト

### 02 意図バイアス

**Intentionality Bias / 意图偏见**

> 無生物・偶然・複雑な創発システムの背後に、意図や目的を持つ主体を想定してしまう傾向。
> *The tendency to assume that inanimate objects, random events, or complex emergent systems are controlled by a conscious agent with a specific purpose or will.*
> 倾向于假设无生命体、随机事件或复杂的涌现系统由具有特定目的或意志的有意识主体所操纵。

誰も操縦していない世界は、寒い。市場、アルゴリズム、資本、歴史——複雑な創発の背後に、人格を置きたくなる。古代の神も、現代の「黒幕」も、「世界の裏で糸を引く誰か」という同じ構図の裾野にいる。

これは道徳的な直観の裏面でもある。責任を問うには、まず「意図した主体」が要る。誰かのせいにしたいという欲望は、しばしば因果の説明より先に、容疑者を作る。日本語では、アニミズム的投影、目的論的解釈、神格化が近い。

**関連語:** 目的論的誤謬 / アニミズム的投影 / 過活性な主体検出 (HADD) / 神格化

### 03 因果の錯覚

**Causal Illusion / Illusory Correlation / 因果执念**

> 実際には結びついていない二つの出来事の間に、因果を見てしまう錯覚。
> *The false belief that two events are causally related when they are not, often driven by an inability to accept the pure, unattached present moment.*
> 由于无法接受纯粹、无着落的「当下」，进而错误地相信两个本无关联的事件之间存在因果关系的虚假信念。

二つの出来事が続けて起きると、脳は「だから」と接続詞を補う。相関は因果ではない、と知っていても、体はそう感じる。因果は時間を一本の線に変え、過去を遡って原因を探させ、未来を先取りして結果を恐れさせる。因果応報、宿命、終末予言——どれも、この線の上に描かれた物語だ。

介入と反実仮想は、因果を物語から検証へ引き戻す道具である。相関を見たら、まず「触ったら変わるか」を問う。

**関連語:** 錯誤相関 / 事後の物語化 / 反実仮想 / 永遠の今

## 三つは直列につながっている

```
01 形を見つける  →  02 主体を読む  →  03 物語に縫う
   Pattern            Agent              Cause
```

パターン性向が見つけた「形」に、意図バイアスが「誰か」を読み、因果の錯覚が「なぜ」を縫い合わせる。三つは別々の欠陥ではなく、一つのパイプライン——意味製造機の三つの工程だ。

予測処理の見方では、脳は常に世界のモデルを走らせ、予測誤差を小さくするように更新する。三つの装置は更新を速める。だが誤差を物語で埋めてしまえば、モデルは世界から離れて独走する。独走したモデルは、世界の説明ではなく、世界の代用品になる。

> 装置を止める必要はない。止められない。必要なのは、いま自分が何を作っているかを、作りながら知っていることだ。

## 点検のための四つの問い

1. **反証条件は何か。** このパターンが崩れると分かる観察は、具体的に何か。
2. **主体なしで説明できるか。** 「誰か」を置く前に、制度・偶然・フィードバックだけで説明を試す。
3. **介入できるか。** 因果を主張するなら、触って変わるか、反実仮想を置けるか。
4. **いま、何が起きているか。** 物語の外側——呼吸、感覚、目の前の作業——に注意を戻す。ただし「今ここ」も、もう一つの物語になりうる。

| 日本語（主軸） | English | 中文 | 近縁の語 |

### 訳語についての注記

- **patternicity** は Michael Shermer の造語。日本語に定訳はなく、「パターン性向」「パターン認識の偏執」などの訳が当てられる。
- **apophenia** は Klaus Conrad の *Apophänie* に由来し、統合失調症の初期体験の記述に使われた語。現在は「無関係なもの同士の関連づけ」を広く指す。patternicity と重なるが同義ではない。
- **intentionality bias** は「意図バイアス」のほか、目的論的推論、過活性な主体検出（HADD）として論じられる。日本語の「意図」は intention と intentionality の双方に対応するため、文脈に注意。
- **causal illusion** は「因果の錯覚」。錯誤相関と重なるが、錯誤相関は相関の過大評価に焦点を当てた実験的パラダイムを指すことが多い。「今ここに耐えられない」という説明は哲学的・仏教的な解釈であり、実証的な定義ではない。
